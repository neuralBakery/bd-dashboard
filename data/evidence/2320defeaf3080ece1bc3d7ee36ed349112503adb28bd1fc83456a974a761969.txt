You'll work closely with our engineering, manufacturing and project teams to build state-of-the-art equipment that is deployed across Australia and New Zealand. Occasional travel to customer sites across Australia and overseas is required, including some time away from home.</p>

<li>Troubleshoot and provide technical support for control system issues.</li>

		function setCookie(key, value) {
			var expires = new Date();
			expires.setTime(expires.getTime() + (1 * 24 * 60 * 60 * 1000));
			document.cookie = key + '=' + value + ';expires=' + expires.toUTCString();
		}
		

		function getCookie(key) {
				var keyValue = document.cookie.match('(^|;) ?' + key + '=([^;]*)(;|$)');
